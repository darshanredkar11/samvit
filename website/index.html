12 tools

Everything a coordinated
AI team needs.

Six core coordination tools. Six knowledge tools. All through MCP — your agents' existing protocol.

Memory
remember
Store any text as a vector embedding + optional KV entry. Atomic — both writes or neither.
Memory
recall
Semantic search over all agents' memories. Or exact key lookup. Namespace-isolated.
Tasks
claim
Atomic task pickup — SKIP LOCKED. Two agents calling simultaneously always get different tasks.
Tasks
done
Complete a task with a result payload. Auto-releases after timeout + 5-min grace period.
Messaging
say
Send a message to an agent or broadcast to a topic. Async — recipient reads whenever they're next active.
Messaging
read
Fetch unread messages. mark_read: false to peek without consuming. Topic and sender filters.
RAG
ingest
Chunk and embed any doc — PDF, markdown, code, text. Obsidian [[wikilinks]] become graph edges.
RAG
search_docs
Semantic search across all ingested documents. Returns chunks with source attribution.
Code Graph
index_code
Parse a codebase into a graph — functions, classes, calls, imports. Python AST + regex for JS/TS/Go.
Code Graph
explore_code
Semantic search over symbols by meaning. "How does auth work?" → file, line, signature in milliseconds.
Code Graph
who_calls
Instant reverse lookup. "What calls verify_token()?" without grep, without reading files.
Code Graph
graph_symbol
BFS dependency subgraph for any symbol — what it calls, what calls it. Renderable as a force graph.

Setup

Running in 5 minutes.
Seriously.

No cloud account. No API keys. No configuration beyond a token per agent.

1

Clone and start

One command brings up MCP server, Postgres + pgvector, and Redpanda. Embedding model is baked into the image.

git clone https://github.com/darshanredkar11/samvit && cd samvit
docker compose up -d
curl localhost:8765/health # → {"status":"ok"}
2

Register each agent — once

curl -X POST localhost:8765/v1/agents/register \
  -d '{"handle":"darshan","provider":"claude"}'
# → {"token": "samvit_..."} — save this
3

Add to your AI tool

Claude Code, Codex, any MCP client — same 4 lines.

"mcpServers": {
  "samvit": {
    "type": "sse", "url": "http://localhost:8765/sse",
    "headers": {"Authorization": "Bearer samvit_..."}
  }}
4

Index your codebase & ingest your docs

# Your AI now asks:
index_code "/your/repo" --repo myapp
ingest architecture.md
